# Assets Architecture

The `/src/assets/` directory houses local media assets compiled by Vite.

## Folders Category

- `logos/` — Corporate logos and brand files
- `icons/` — Inline SVGs and custom icons
- `images/` — Compressed photos and graphics
- `illustrations/` — Vector graphics and sketches
- `backgrounds/` — Canvas starfields and gradient patterns
- `videos/` — Compact loop animations
- `fonts/` — Custom typography files (not loaded via Fontsource)
