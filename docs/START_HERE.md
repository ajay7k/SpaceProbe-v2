## First Setup Steps

1. Install dependencies:
   ```bash
   npm install
   ```
2. Launch dev server:
   ```bash
   npm run dev
   ```
3. Run linting check:
   ```bash
   npm run lint
   ```
4. Check TS types:
   ```bash
   npm run typecheck
   ```
