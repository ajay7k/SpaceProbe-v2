# Public Directory Assets

The `/public/` directory holds raw assets copied directly to the build output root without bundling or compression.

## Required Assets

- `favicon.ico` — Site tab icon
- `icon-192.png`, `icon-512.png` — Standard manifest app icons
- `site.webmanifest` — Web App Manifest config
- `robots.txt` — Search engine directive paths
- `sitemap.xml` — Sitemap indexing file (scaffolded later)
- `og-share.jpg` — OpenGraph social sharing preview image card
